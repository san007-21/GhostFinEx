# Brainstorm the best version

This pass applies only when the user asked for something to be built and left its shape to you. If the request was to investigate, fix, or change a specific behavior, report that there is nothing in scope to brainstorm and stop.

Do not change anything. Use the product briefly through its real surface, then brainstorm at least five concrete ways it could be meaningfully better — deeper where it is shallow, more delightful where it is flat, more replayable or more worth returning to — judged by what the request MEANS rather than what it spells out. Ideas must stay inside the request’s own meaning; a different product is out of bounds.

For each idea: what it is, why a demanding user would notice it, and roughly what it costs. Rank them by value for cost, name the top two, and say exactly what building the first one would involve so the next pass can start cold.
