# GhostFinEx

AI-powered student financial decision assistant for budgeting, saving, smart shopping, and financial education.

## Vision

GhostFinEx helps students understand their money, compare options, and make informed financial decisions without pretending to be a financial guru.

## Core Features

- Budget and expense tracking
- Savings goals
- Subscription tracking
- Smart shopping and price comparison
- Financial education
- AI-powered financial decision support

## Core Principle

**Educate → Explain → Compare → Recommend options → Let the user decide.**

## Project Status

🚧 Early development

GhostFinEx is being built from the ground up as part of an active hackathon development cycle.

## Planned Stack

- Frontend: React / Next.js
- Backend: Supabase
- Database: PostgreSQL
- Authentication: Supabase Auth
- AI: RAG + AI model
- Search: API-based product/search data
- Version Control: Git + GitHub
